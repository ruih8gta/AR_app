# てのひらサファリ 要件

Androidのカメラ映像に恐竜や動物の3Dモデルを表示し、実際の床や机に立っているように眺めるアプリ。名前は仮称。

## 確定要件

- Androidアプリとして動く。
- 恐竜・動物の立体モデルをカメラ映像に直接重ねる。
- モデルが動く。
- 要件とデモを先に作り、その後アプリ開発へ進む。
- デモでも3Dモデル自体を見られる。
- 開発環境は隣の `android-compose-starter` を参考にする。

## 初版の仮仕様

| 項目 | 初版 |
|---|---|
| モデル | オリジナルの簡易ローポリ恐竜とキツネ |
| 配置 | 床・机など上向きの水平面を検出し、タップで1体配置 |
| ARの意味 | 現実の位置に固定した立体を、スマホを動かして別角度から見られる |
| 動き | 待機（呼吸・しっぽ）、その場の足ぶみ、一時停止 |
| 調整 | 大きさ0.5〜1.5倍、向き、置き直し |
| 選択 | 同じ場所のモデルを切り替える |
| プレビュー | カメラを使わず3D表示・回転・拡縮・動作を試せる |
| 保存 | 配置場所は保存せず、AR終了時にリセット |
| データ | アカウント不要。独自の画像送信・録画・広告・解析SDKなし |
| 実機 | 機種名は後で確認。対応・動作は未確認 |

チャットのデモは仮の3D背景上のプレビューで、カメラや現実の平面認識は使わない。「足ぶみ」は位置を変えない。高精細なモデル、自律的な散歩、鳴き声、撮影保存、複数配置、現実物体による遮蔽、設置場所の永続保存は次段階の候補。

## 利用の流れ

1. **3Dプレビュー**でモデル・動き・大きさ・向きを試す。
2. **ARをはじめる**でカメラの用途とARサービスの説明、対応判定、必要なインストール案内。
3. **面を探す**ためカメラをゆっくり動かす。検出場所にリングが現れる。
4. **タップで置く**とモデルが立つ。スマホを動かして別の角度から見る。
5. **動かす・調整**で足ぶみ・待機・停止、大きさ・向き変更、置き直し。

## エラーと復帰

- カメラ拒否：再試行・アプリ設定・プレビューへ戻る導線。
- AR非対応：理由を表示し、3Dプレビューは利用可能。
- 面が見つからない：明るさ・模様のある面・ゆっくり動かす案内。
- 追跡喪失：モデルを一時的に隠し、追跡復帰で表示を戻す。
- バックグラウンド：カメラと描画を休止。復帰時にセッション再開。
- カメラの競合・開始失敗：再試行・プレビューへ戻る導線。

## 受け入れ条件

- デモで2種類の立体・回転・拡縮・アニメーション・停止を操作できる。
- Androidプレビューはカメラ権限なしで開く。
- 対応実機でカメラ映像と3Dモデルが同じ画面に表示される。
- 検出した水平面に1体だけ配置し、スマホ移動後もその場所に見える。
- モデル・サイズ・向き・動き・置き直しが反映される。
- 非対応・権限拒否・追跡喪失・アプリ復帰で落ちない。
- PCテスト・Lint・APKビルドと、実機によるAR確認を別々に記録する。

## 技術条件

ARはAndroid 7.0以降かつARCore対応端末・Google Play開発者サービス（AR）が必要。プレビューがあるためAR Optionalとする。実機のOS・地域などの条件も[Google公式対応表](https://developers.google.com/ar/devices)で確認する。
